`technical-report.html` and `report.css` are the canonical report source. Open the HTML in a browser alongside its local image/font assets. Its print stylesheet uses A4 pages; the published PDF was rendered with Chromium, backgrounds enabled, and a page-number footer. The public site mirrors these assets under `research/capture-loop/report/`.

The report pins implementation commit `8873e7768f266786c4b5d7b42a9f555c940b3753`. The full-label comparison reuses its four explicitly named historical cloud sessions. The paired-field chapter uses the released field/detail implementation and its independently named evidence files. `evidence/report-selected.json` and `report-domain.json` are current local reruns, while `compare-controllers.py` reproduces the action comparison directly from the four recorded sessions.
