Its print stylesheet uses A4 pages; the published PDF was rendered with Chromium, backgrounds enabled, and a page-number footer. The public site mirrors these assets under `research/capture-loop/report/`.

The report pins implementation commit `2fb59914d1dee7140b0c955c027f33eb6e1a90fe`. The recorded cloud traces use the preceding image implementation; the added review executor contract also accepts their four eligible review observations. `evidence/report-selected.json` and `report-domain.json` are current local reruns, while `compare-controllers.py` reproduces the action comparison directly from the four recorded sessions.
